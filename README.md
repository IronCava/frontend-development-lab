# Frontend Development Lab

**HTML5 · CSS3 · Sass · Bootstrap · JavaScript**

A curated collection of **35 frontend development exercises** exploring core client-side technologies, from semantic HTML and responsive layouts to JavaScript logic, DOM manipulation and interactive interfaces.

> This repository is organized as a **conceptual development path**, rather than a chronological representation of my overall experience as a developer.

## About This Repository

Frontend Development Lab brings together a series of practical exercises focused on different areas of client-side web development.

The repository covers progressively more complex concepts, including:

* Semantic HTML5
* CSS layouts and Flexbox
* Forms and multimedia
* CSS animations and transitions
* Responsive web design
* Bootstrap
* Sass
* JavaScript fundamentals
* Conditional logic and loops
* Functions
* Arrays and objects
* DOM manipulation
* User interaction
* Interactive application logic

Rather than presenting each exercise as an individual project, this repository preserves them as a **technical development lab**, showing how different frontend concepts can be isolated, explored and implemented through practical examples.

---

## 🧭 Development Path

The exercises can be understood through eight main areas:

### 01 — HTML Foundations

Semantic structure, content hierarchy, links, lists, images and fundamental HTML elements.

### 02 — Layout & Flexbox

CSS styling, positioning, Flexbox, page composition and increasingly complex layouts.

### 03 — Forms & Multimedia

Forms, input elements, audio, video and integration of multimedia content.

### 04 — CSS Motion

Transitions, transformations, keyframe animations and visual interaction using CSS.

### 05 — Bootstrap & Sass

Responsive layouts, Bootstrap components, grid systems and CSS preprocessing with Sass.

### 06 — JavaScript Logic

Variables, operators, conditional statements, loops and fundamental programming logic.

### 07 — Functions & Arrays

Reusable functions, data manipulation, array methods and dynamic operations.

### 08 — Objects & Interaction

JavaScript objects, collections, DOM manipulation, events and interactive interface behaviour.

## ⭐ Featured Exercises

Among the 35 exercises, these examples represent some of the most complete implementations in the repository.

### JavaScript Calculator

An interactive calculator built with JavaScript and structured around a `Calculadora` class.

It includes:

* Arithmetic operations
* Percentage calculations
* Positive/negative values
* Square and square-root operations
* Inverse calculation
* Input management
* Dynamic display updates
* Event-driven interaction

**Concepts:** JavaScript classes · application state · methods · events · DOM manipulation

---

### JavaScript Objects Lab

A practical exploration of JavaScript objects and collections.

It works with:

* Object creation and modification
* Arrays of objects
* Spread syntax
* `Object.keys()`
* `Object.values()`
* Property deletion
* Object iteration
* Dynamic interface elements

**Concepts:** Objects · data structures · iteration · JavaScript methods · DOM

---

### Guest List Manager

An interactive exercise focused on managing collections of data through JavaScript.

Operations include:

* Adding elements
* Removing elements
* Combining arrays
* Searching values
* Transforming data
* Displaying results dynamically

**Concepts:** Arrays · `push()` · `splice()` · `shift()` · `concat()` · `map()` · `includes()`

---

### Bootstrap Layout

A responsive interface developed using the Bootstrap grid system and reusable components.

The exercise explores the implementation of a **Holy Grail layout** while combining Bootstrap utilities with custom CSS.

**Concepts:** Bootstrap · responsive design · grid systems · components · layout architecture

---

### Corporate Website

A more complete interface exercise focused on combining structure, styling and visual hierarchy in a website closer to a real-world business context.

**Concepts:** HTML · CSS · page architecture · navigation · visual hierarchy · responsive design

## 🎓 Background & Context

The exercises in this repository were completed as part of **MF0491_3 — Client-Side Web Programming**, studied at **Ironhack**.

The module followed a structured syllabus covering frontend concepts from HTML and CSS fundamentals through JavaScript programming and browser interaction.

However, this sequence should **not be interpreted as a timeline of my overall development experience**.

Before completing this module, I had already finished university-level studies involving web development and programming and had worked on larger academic and personal projects.

For that reason, some exercises intentionally use simpler approaches or focus on isolated concepts in order to meet the specific objectives of the training module.

The repository has been preserved and later curated as part of my development portfolio because it provides a useful record of implementing frontend concepts individually and systematically.
